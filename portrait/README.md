# Portrait projections

A portrait projection is a compact, purpose-bounded view generated from
reviewed claims. It is not the canonical person record and must not become a
model-written biography that is silently trusted forever.

Every projection must declare:

- purpose and intended reader;
- generation and review date;
- included claim IDs;
- excluded or unresolved scope;
- expiry or next review condition.

Initial templates:

- `KERNEL.md` for relatively durable patterns;
- `NOW.md` for current, changeable context;
- `COUNTERWEIGHTS.md` for contradiction and anti-overgeneralization.

Only accepted claims should normally support positive portrait statements.
Contested claims and material counterevidence belong in `COUNTERWEIGHTS` or an
explicit unresolved section. Retired claims may be used only to explain change.
