# Dionysus reflection UI guidance

This surface is a local, static pre-interview workbook. It may collect real
personal text in the browser, but the repository owns only the public UI and
its data contract.

- Do not add analytics, telemetry, remote fonts, third-party scripts, network
  requests, accounts, or a backend.
- Keep drafts local to the browser. Export and deletion require an explicit
  person action.
- Treat `localStorage` as convenience storage, not as an encrypted vault. Say
  so in the interface.
- Embed only Dionysus-authored prompts allowed by the current instrument and
  interview contracts. Do not copy protected items, scoring keys, or norms.
- Do not produce diagnoses, types, percentiles, rankings, or personality
  verdicts. Reflections may only route questions for a later interview.
- Preserve skip, correction, pause, export, and deletion controls.
- Keep all committed sample language fictional or generic.
